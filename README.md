# Professional Birthday Proposal Website 🍒💗

A polished, mobile-first, smooth animated proposal website for Chanchal.

## Preview
Open `index.html` in any modern browser.

## Add the music
Because copyrighted songs should not be redistributed inside this ZIP, add your own legally obtained audio file:

`assets/rangrez.mp3`

The website already includes the **Our song** button.

## Publish on GitHub Pages
1. Create a new GitHub repository.
2. Upload all files from this project.
3. Go to **Settings → Pages**.
4. Under Build and deployment choose **Deploy from a branch**.
5. Select `main` branch and `/root`.
6. Save and wait for GitHub to generate your website link.

Files:
- index.html
- style.css
- script.js
- assets/
